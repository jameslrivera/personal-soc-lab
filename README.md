# Cybersecurity Home Lab

## Overview
Building a SIEM/EDR lab with ELK Stack on macOS, vulnerable Windows VM, 
Kali attacker, Suricata, and Lima Charlie.

## Components
- SIEM: ELK Stack
- Victim: Vulnerable Windows VM
- Attacker: Kali Linux VM
- IDS/IPS: Suricata
- EDR: Lima Charlie
